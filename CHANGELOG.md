# JINX MOD MENU v0.6.20 — Plutonium T6 Multiplayer

Private-match GSC menu by Jinx with 17 categories, customizable UI, practice tools, live custom modes and host administration.

## This release

- Reduces the menu HUD from 48 to 32 elements to address missing rows, counters and control hints.
- Shows one right-aligned arrow or state indicator beside the selected option.
- Retains all 17 categories and existing gameplay features.

- Removes unsupported menu entries and failed Light Sabers / Invert Controls options.
- Keeps the existing 17 categories and navigation.
- Adds automatic Crazy Vision styling while the menu is open, with normal vision restored on close.
- Removes the separate Crazy Vision option from Game Mods Menu.
- Limits Map Menu to reloading the current map and displaying map information.

## Install

Download **JINX-T6-v0.6.20.zip**, extract it, and copy `jinx_menu.gsc` to:

```text
%localappdata%\Plutonium\storage\t6\scripts\mp
```

Host a private Multiplayer match and open with **ADS + Melee**. Release both inputs before navigating. See README.md for controls and troubleshooting.

The author confirmed this version working in their private-match setup. T6 PC source compilation also passed. Private/local use only; no DLL or injector required.
